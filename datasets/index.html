Ars Magica Open License 0.4.2

A reference dataset built from 25 books of the Ars Magica Open License, the tabletop role-playing game released under CC-BY-SA 4.0.

Packs (books)25, one core book plus supplements, with requires dependencies
Entities3,866: tags, characters, spells, places, factions, creatures, items…
Chunks and vectors17,942 each; nomic-embed-text, 768 dimensions
Aligned withrpg-schema (domain schema); schema.org, Dublin Core, FOAF
LicenceCC-BY-SA 4.0

Publish your own

  1. Run the pipeline over your documents and approve the schema card.
  2. Publish with ontorag hub push, which creates a private GitHub repository by default, or lay the directory out by hand.
  3. Check it against the compliance list and validate manifest.json against the schema.
  4. Serve it with ontorag-mcp by pointing a client at <owner>/<repo>.

Only publish content you have the right to redistribute. If you split a dataset into packs, you can serve protected sources only to consumers entitled to them. See packs.
