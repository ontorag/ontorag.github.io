ontorag, the CLI and library Beta · 0.1.12

The whole pipeline as a Python package: ingest, schema proposal and alignment, deterministic schema cards, instance extraction with provenance, vector indexing, publishing, and SPARQL and MCP servers. Apache-2.0, Python 3.12 or later.

ontorag-mcp, answers from published datasets Public

An MCP server that reads any published dataset in place from GitHub, addressed as <owner>/<repo>, with no clone and no database. Private repositories work with a GitHub token.

ToolDoes
list_datasets, load_datasetList and load datasets (with a git ref and retrieval mode)
searchRetrieve passages
answerOntology facts plus cited passages for a question
search_entities, get_entityFind and describe entities
entity_chunksThe passages that mention an entity

Retrieval modes are ontology, vector and hybrid, with an optional Redis cache. It runs with Docker, over stdio, or serverless.

claude mcp add --transport http ontorag http://localhost:8765/mcp

Ontology catalog Public

A catalog of baseline ontologies that pipelines align to. You can list, inspect, search classes and properties, and compose a set of baselines into an initial schema card. It is available as MCP and REST at https://mcp.rpg-schema.org/mcp, the default source for ontorag init-schema-card. It currently holds rpg-schema, schema.org, FOAF and Dublin Core, plus game-system vocabularies (fitd, cbrpnk, gumshoe). You can run your own with ontorag ontology-mcp.

Hub In development

A web app for running the governed pipeline without the command line:

  1. Sign in with GitHub and upload a corpus.
  2. Pick baselines, then review the proposed schema as an editable diff.
  3. Approve, which commits the card, then extract.
  4. Publish, and chat with the dataset through guarded, read-only SPARQL with citations.

Datasets live in your own GitHub repositories, and heavy stages run in your own GitHub Actions with your own model key. The Hub is not public yet.

Desktop In development

The Hub workflow as a local-first desktop app. A dataset is a local git clone, the pipeline runs on your machine with the engine bundled (no Python install), and chat runs against a local SPARQL server. It is not public yet.
